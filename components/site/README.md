# components/site

Pieces shared by every page.

| File | Purpose |
| --- | --- |
| `Nav.tsx` | Fixed top nav: SQYC wordmark and the section links |
| `SectionClose.tsx` / `close.styles.ts` | The × back to Home on Art and Places; the mark is shared with the About drawer's close |
| `BackLink.tsx` | "← All …" back to a section's overview, accent-coloured, at the top of a location or an article |
| `Nav.styles.ts` | Tailwind classes for the nav |
| `Nav.css` | `top-nav-glass` utility: the frosted band behind the nav |
| `page.styles.ts` | Classes shared by the scrolling content pages (`main`, container, title, small links) |
