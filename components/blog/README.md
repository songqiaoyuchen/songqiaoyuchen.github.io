# components/blog

Blog UI and the components available inside MDX articles (`mdx-components.tsx`).

| File | Purpose |
| --- | --- |
| `ArticleList.tsx` | `/blog` archive rows |
| `ArticleHeader.tsx` | Article title, deck, date, reading time and tags |
| `Callout.tsx` | MDX `<Callout>` |
| `Figure.tsx` | MDX `<Figure>` |
| `CodeBlock.tsx` | MDX code block wrapper with language label |
| `CopyCodeButton.tsx` | Copy button for code blocks |
| `article.css` | Article typography, code blocks, figures and callouts |
