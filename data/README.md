# data

Site content and copy. Edit these to change what the site says; components only lay it out.

| File | Purpose |
| --- | --- |
| `sections.ts` | Section ids and their visible names |
| `hero.ts` | Homepage hero text and the hover name |
| `about.ts` | About introduction, experience timeline, contact links |
| `projects.ts` | Projects (featured ones appear in the drawer) and the drawer intro |
| `blog.ts` | Blog drawer intro and empty state (articles are MDX in `content/`) |
| `artworks.ts` | Artwork catalogue, medium sections and the featured carousel order |
